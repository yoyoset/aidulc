## 2. 如果你是一个真实用户,你会有什么需求

### 2.1 第一天打开软件

1. **我双击 exe 后能不能直接用?** —— 绿色版能开,但模型/ffmpeg 还在 `F:\hf_cache` 和 `F:\my_ai\subgen`,换个机器就崩。需要真正的"首次运行向导":选数据目录 → 检测硬件 → 下载/复用模型 → 检查通过才进主界面。
2. **我不认识任何技术名词**。用户不该看到"Python 侧车""CUDA""GGUF""ffmpeg"。现在的组件中心显示这些路径,对普通用户是噪音。
3. **我把书拖进来,它多久能读完?** —— 没有预计时间/进度百分比/可暂停。批量 10 本书时我看不到"哪本到哪了"。

### 2.2 读一本书时

4. **字太小/太挤,我想调整** —— 有字号/行距设置,但不够直观(设置藏得深),且改完要重新进阅读器才生效。
5. **我想听原声跟读** —— 有播放/跟读,但**没有单句重听的热键提示、没有句间停顿精细调节、没有"整章循环"**。
6. **我看到不认识的词,点了没反应或只有一行字** —— 词典面板太弱。用户要的是:词义、词性、音标、例句、发音,一个完整弹窗;然后一个明显的"加入生词本"按钮。
7. **我想复习今天存的词** —— 生词本只有"加入",**没有页面可以看自己存了哪些词、按时间/书本筛选、导出**。
8. **我读到一半关电脑,回来要能找到位置** —— 已实现,但用户不知道它记住了,没反馈。

### 2.3 长期使用

9. **我存了几百个词,怕丢** —— 需要:生词本导出/备份,或至少看得见"本地数据在哪"。
10. **我换了电脑/想手机接着背** —— 这是 AIDU 同步的意义,但当前**没有同步入口 UI**,用户不知道怎么配。
11. **我想知道我这周读了多少** —— 阅读统计(时间/字数/词数)完全没有。
12. **书太多找不到** —— 书库只有简单列表,没有**搜索/筛选/最近阅读排序**。
13. **某本书读了一半不想读了** —— 需要:删除/归档/标记完成,而不是只有"删除"。

### 2.4 出错时

14. **任务失败了,我只看到红色"失败"** —— 用户要:为什么失败、哪句失败、怎么重试、日志在哪。
15. **软件升级后书会不会没** —— 用户不知道升级安全。需要:明确的"更新不会动你的书"保证 + 数据备份提示。

### 2.5 性能和稳定性

16. **打开一章等多久?** —— 长章加载慢,用户没耐心。需要:骨架屏/渐进渲染/打开反馈。
17. **读长书会不会卡** —— 虚拟列表未做,3000+ 句一章的 DOM 可能卡。
18. **音频能不能拖动进度** —— 有进度条,但**没有章节内拖动到任意句**的精细控制。

## 3. 需求优先级 (用户视角 → 产品优先级)

### P0: 不用它就无法正常使用
- 首次运行向导(模型/组件检测 + 修复入口)
- 组件中心不暴露技术路径,改为"需要下载 → 一键下载"的纯用户界面
- 任务失败的可读反馈(为什么/怎么重试)

### P1: 每天用都会碰到
- 完整词典弹窗(释义/音标/例句/发音)
- 生词本页面(列表/筛选/删除/导出)
- 书签面板(列表/跳转)
- 同步配置入口(Worker URL + token)
- 书库搜索/筛选/最近阅读

### P2: 提升体验
- 阅读统计(时间/词数/生词数)
- 书的目标管理(在读/完成/归档)
- 跟读精细控制(句间停顿/整章循环/热键提示)
- 打开长章渐进渲染/骨架屏

### P3: 锦上添花
- 深色模式细化、字体预览
- 生词本导出 CSV/JSON
- 学习提醒/每日目标
- 多语言 UI(界面语言切换,不只是书的内容语言)

## 4. 当前技术与用户需求的差距

| 用户需求 | 当前状态 | 差距 |
|---|---|---|
| 模型/依赖不折腾 | 组件中心显示路径 | 需用户界面化 + 下载能力 |
| 失败可读 | 状态栏文本 | 需结构化错误 + 重试入口 |
| 生词本完整 | 只有加入按钮 | 需页面/筛选/导出 |
| 词典完整 | 状态栏一行 | 需弹窗面板 |
| 同步可见 | 命令存在无 UI | 需配置页 + 状态展示 |
| 书签管理 | 双击标记 | 需面板/跳转 |
| 阅读统计 | 无 | 需统计页 |
| 长章流畅 | 未做虚拟列表 | 需窗口化渲染 |

## 5. 建议下一步

按用户价值排序:

1. **首次运行向导** —— 用户打开软件的第一体验,决定是否继续用。
2. **生词本页面 + 完整词典弹窗** —— 核心学习闭环。
3. **任务失败可读反馈** —— 信任问题,失败必须能看懂。
4. **同步配置入口** —— AIDU 数据闭环的用户可见部分。
5. **书签面板 + 书库搜索** —— 日常使用效率。
6. **长章虚拟列表** —— 性能体验。
