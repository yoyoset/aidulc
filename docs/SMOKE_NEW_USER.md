# 新用户走查清单(发版前人工走一遍)

> 为什么有这份: 项目上线三个月后, 最近的修复仍是"空书库找不到任何导入入口"
> (`c7e4574`)、"模型页看不懂当前推荐 / 兜底"(`eb5fbfa`)这一级的问题 —— 自动化冒烟
> 用的是 DOM stub, 摸不到"真实窗口里一个新用户走不走得通"。这份清单补的就是这一层。
> 它比再做一轮 UX 审计便宜, 而且可重复: 每次发版前走一遍, 发现的问题记回 `ROADMAP.md`。

## 准备(每次走查都要做)

1. **用全新的数据目录**, 不要在自己的真实书库上走。便携版: 把 exe 复制到一个空文件夹再运行。
   安装版: 先把 `%APPDATA%\aidulc` 改名备份(走完再改回来), 并确认 `data_root.txt` 指针文件不存在。
2. 记下版本号(设置 →「系统与书库」→「关于」)和 `git log --oneline -1`, 写进走查记录。
3. 准备一本 **300 句以内的短 EPUB**(不要拿整本书, 备料要几小时)。

## 10 步(每步写"实际看到了什么", 不是"通过")

| # | 做什么 | 应该看到 | 重点盯 |
|---|---|---|---|
| 1 | 首次启动 | 先出现**首次设置向导**, 侧栏不可点; 不应先看到空书库 | 向导没走完时能否被误退出 |
| 2 | 向导 6 步走完: 语言 → 数据目录 → 硬件检查 → 模型发现 → 依赖清单 → 完成 | 每步都有"为什么问你这个"的一句话; 缺模型/缺依赖时**明说缺**, 不写"已就绪" | 「数据目录」步能否改位置; 磁盘空间显示的是目标盘 |
| 3 | 完成页选「① 先读一本内置样书 (推荐)」 | 书库里出现样书(爱丽丝梦游仙境片段), 点开能读、**点播放有声音且逐句高亮**、能点词查释义 | **没装任何模型也能读也能听**; 声音和高亮对得上吗; 样书 3 章共 11 句 |
| 4 | 书库导入你准备的短 EPUB | 导入前有体检结果; 原书卡出现 | 空书库时导入入口在哪里、找不找得到 |
| 5 | 原书卡点「创建译本」→「开始备料」 | 备料页出现任务, 进度/阶段是中文, 有预计剩余时间 | 暂停 → 继续能否从断点续跑; 选的档案是否被记住 |
| 6 | 备料完成 | 应用内 toast 提示完成; **切去别的窗口时**还应有一条系统通知(设置 →「系统与书库」→「处理完成通知」可关); 译本能「打开阅读」 | 系统通知有没有真的弹出(WebView 通知权限, 尚未在真机验证); 阅读器里没处理成功的句子有「!」标记; 备料前磁盘不足时是否明说 |
| 7 | 阅读: 切模式(1/2/3)、播放跟读、点词查词 | 高亮跟着声音走; 查词有结果或有明确的失败原因 + 重试 | 第一次查词要几秒(冷启动词典守护), 界面有没有"查词中…" |
| 8 | 加几个生词 → 生词本 →「开始复习」 | 词条带来源句; 复习卡可翻面评分 | 阅读器里按 s / 数字键不能误给隐藏卡片打分 |
| 9 | 生词本「备份」下载 .aidu-data → 另存 → 「恢复」 | 提示"已恢复 N 个生词"; **有没导进来的会明说几条** | 数字对得上吗 |
| 10 | **模拟丢库恢复**: 关闭应用 → 改名数据根目录(或移走移动硬盘)→ 重新打开 | 弹「找不到书库」, **点外部关不掉**; 有「从快照恢复数据…」, 列出日期和生词数; 恢复后**重启**数据回来 | 快照列表是否有; 恢复完成后提示重启 |

## 每步通用检查

- 失败时界面说的是**人话 + 能做的动作**, 不是只有技术报错。
- 任何"成功"提示后, 实际状态真的变了(刷新/重开确认)。
- 没有按钮点了没反应。
- 深色模式下文字都读得清(`设置 → 阅读` 切换)。

## 专项: 2026-11 新增功能(都只有单测, 没人在真实窗口用过 —— 这是第一次)

每项写"实际看到了什么"。**任何一项和预期不符都算发现问题, 不要自己圆过去。**

| 功能 | 怎么触发 | 预期 | 失败了意味着 |
|---|---|---|---|
| **样书带朗读** (E1) | 全新数据目录 → 向导 → ①先读内置样书 → 书库点开 → 播放 | 3 章 11 句; 有声音; 高亮逐句跟着走; 点词能查; 章节切换音频不串 | 声音和高亮错位 = 音频/时间轴资产有问题, 要重新生成样书 |
| **老样书升级** (E1) | 在装过旧版的数据目录里再点一次导入样书 | 目录里补出 `audio/`, 不会在书库里出现第二本 | 出现两本 = 登记 id 不幂等 |
| **系统通知** (E3) | 备料一本短书; 开始后**切去别的窗口**等它完成 | 弹出 Windows 系统通知(完成/失败文案不同); 窗口在前台时只有页内 toast | **不弹是最可能的发现**(WebView2 对 Notification 的行为没验证), 记下是没弹还是弹了没权限提示 |
| **通知开关** (E3) | 设置 →「系统与书库」→「处理完成通知」取消勾选, 再备料一本 | 不再弹; 重启后开关状态保持 | 状态不保持 = localStorage 没写进去 |
| **磁盘预检** (E4) | 找一个可用空间 < 2 GB 的盘当数据目录(或用小容量虚拟盘), 点开始备料 | 拒绝开始, 提示写明剩余/需要多少 GB 和"清理或迁移数据目录" | 照常开始 = 预检没生效; 提示里数字不对 = 查错盘了 |
| **失败句标记** (E2) | 打开一本有失败句的书(可手动改 bookpack 里某句 `status`: `partial`、`failedStages`: `["tts"]`) | 该句旁常显「!」; 点开说明缺朗读且"播放时是静音"; 点「重试失败句」有反馈 | 看不到「!」= 渲染没读字段; 重试报"任务不存在" = 反查任务失败 |
| **丢库恢复** (S2) | 见上面第 10 步 | 同上 | 同上 |
| **检查更新** (D4) | 设置 →「关于」→「检查更新」 | 目前仓库没发布过 Release, 应显示"还没有发布过正式版本, 当前 v…"; 断网时是明确的失败提示 | 一直"检查中…"不返回 = 超时没处理 |
| **读屏/减少动态** (E7) | 开 Windows 讲述人读几个图标按钮; 系统设置里打开"减少动画"后切章/滚动 | 图标按钮能读出名字(不是"按钮"); 滚动不再平滑动画 | 读成"按钮" = aria-label 漏了某处 |
